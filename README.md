## About

I'm a software developer focused on building structured, scalable, and maintainable systems across **Roblox** and the web.

My work ranges from Roblox networking, data management, optimization, and reusable frameworks to full-stack web applications, APIs, infrastructure, and developer tooling.

I focus heavily on architecture and abstraction, building systems that simplify development while remaining flexible enough for larger projects.

## Projects

### Pulse

A modular Roblox development framework designed to simplify common systems and provide a consistent development layer across projects.

Pulse includes systems for:

* Networking and event abstraction
* HTTP requests
* Data and DataStore management
* ProfileStore integration
* Validation
* Proxies
* Modular utilities
* Framework-level abstractions

### GFramework

A general-purpose Roblox framework designed to provide reusable architecture and services for larger Roblox projects.

Built around modularity, organization, scalability, and reducing duplicated logic across game systems.

### ARES

A development project focused on automation, tooling, and intelligent systems.

ARES is part of my work on building more capable development infrastructure and experimenting with AI-assisted workflows.

### NEXTRIX STUDIOS

Founder of **NEXTRIX STUDIOS**, a development organization focused on software, Roblox development, community projects, and developer tooling.

I work on the technical direction, infrastructure, internal systems, and development of projects produced under NEXTRIX.
